# Angelo Kannangara | Portfolio

Personal portfolio of Angelo Kannangara: software engineer, Flutter developer and robotics enthusiast based in Sri Lanka. It covers my projects, areas of focus and academic journey.

🌐 **Live site:** [angelokannangara.me](https://angelokannangara.me/)



## Highlights

- **Single-file site:** one `index.html` with inline CSS and JavaScript, no build step and no dependencies
- **Animated starfield** drawn on a canvas, with a parallax effect on scroll
- **Optional ambient sound**, a synthesized drone generated with the Web Audio API (off by default)
- **Scroll-reveal animations** and a cursor spotlight on cards
- **Responsive layout** with a mobile menu drawer and safe-area support for phones
- **Accessible:** respects `prefers-reduced-motion`, uses semantic HTML and keeps keyboard focus visible
- **SEO ready:** Open Graph tags, canonical URL and JSON-LD `Person` markup

## Built with

- HTML5, CSS3 and vanilla JavaScript
- [Manrope](https://fonts.google.com/specimen/Manrope) and [DM Mono](https://fonts.google.com/specimen/DM+Mono) from Google Fonts (SIL Open Font License)

## Run it locally

```bash
git clone https://github.com/angelokannangara/Portfolio.git
cd REPO_NAME
```

Open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```

## Deployment

The site is static, so it works on any static host (GitHub Pages, Netlify, Vercel or Cloudflare Pages). Point the host at the repository root. No build command is needed.
